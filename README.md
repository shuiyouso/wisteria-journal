# 紫藤花语 · Wisteria Journal

一个私人的记录网站：幸福收藏、西格的话、心情花笺。
纯静态，零依赖，数据只存在你自己的浏览器里。

---

## 一、它是什么

三个相互独立的模块：

| 模块 | 存什么 | 字段 |
|---|---|---|
| 幸福收藏 | 让你开心、温暖、值得珍藏的事 | 标题 / 日期 / 内容 / 图片 / 标签 |
| 西格的话 | 西格想对你说的话，长短不限 | 内容 / 日期 / 标题（可选）/ 标签 |
| 心情花笺 | 发生了什么 + 当时的感受 | 事情 / 情绪（多选） / 身体感受 / 想法 / 后来的发现 / 留给自己 / 日期 / 关键词 |

首页显示三个模块的入口、各自条数，以及最近更新的 5 条记录。

## 二、目录结构

```
wisteria-journal/
├─ index.html                 入口页
├─ manifest.webmanifest       PWA 配置（可加到手机桌面）
├─ assets/
│  ├─ css/style.css           全部样式
│  ├─ js/db.js                IndexedDB 封装
│  ├─ js/util.js              工具函数
│  ├─ js/app.js               界面与逻辑
│  └─ img/icon-192.png, icon-512.png
├─ README.md                  本文件
├─ DEPLOY.md                  部署到 GitHub Pages
├─ BACKUP.md                  备份与恢复
├─ MIGRATION.md               旧数据迁移
└─ TEST.md                    测试清单与结果
```

没有构建步骤，没有 npm，没有框架。

## 三、本地预览

三种都行：

1. **直接双击 `index.html`** —— 能跑，数据和旧站是同一个数据库（同一浏览器、同一域名下才共享）。
2. 起一个静态服务（推荐，路由和 PWA 更正常）：
   ```bash
   cd wisteria-journal
   python -m http.server 8080
   # 打开 http://localhost:8080
   ```
3. VS Code 的 Live Server 插件。

> 注意：`file://` 打开时 IndexedDB 可用，但和 `https://` 域名下的数据**不互通**。本地测试的数据不会自动出现在线上。

## 四、数据存哪

- 数据库名：`wisteria-happiness-db`（**与旧版相同**），版本 3
- 表：`entries`（幸福收藏）、`sig_words`（西格的话）、`mood`（心情花笺）、`meta`（自定义情绪）
- 图片以 dataURL 形式存在 `entries.images` 里，单张上限 1.5MB
- 不联网、不上传、不写进仓库

## 五、功能清单

**通用**：新增 / 编辑 / 删除 / 搜索 / 按月份归档 / 显示更多 / 响应式

**幸福收藏**：图片上传（可选）、标签筛选、单模块导出

**西格的话**：标题可留空、正文长度不限

**心情花笺**：20 个默认情绪 + 自定义情绪、快速/完整两种填写模式、按情绪筛选、关键词

**备份**：全部导出、单模块导出、Markdown 导出、导入（合并去重 / 替换）、旧格式兼容、导入前摘要确认、导入失败不动原数据

## 六、版本

- 数据版本：5（导出文件里的 `version`）
- 能读：v5 全部备份、v5 单模块、旧版 v4 单模块
